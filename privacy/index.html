English

What happens to your information

Information you enter

The optional sample profile asks for a name and email. If you create it, those two fields are saved in this browser only. The sample checkout asks for a name, email, phone number, postcode and address. Those contact fields are used on the page while you preview checkout; they are not sent to Ikanza or saved in the sample order history. The wholesale form also stays on the page, is not sent or saved by this site, and is cleared after you view its sample confirmation.

Do not enter a real address, phone number, email or other personal details. The preview does not need them.

What this browser saves

To make the demonstration work, this site stores your sample cart, up to 12 sample order summaries, optional profile name and email, and language choice in your browser's local storage. An order summary contains a generated preview reference, item count, sample delivery area and date, example amounts and creation time. The latest summary is also kept in session storage for the current browser session. No password or payment information is requested.

Local storage remains until you clear it, use the button below, or your browser removes site data. Session storage normally ends with the browser session. The preview does not have a server account, a courier connection, or an email subscription. Refresh any other open Ikanza tabs after clearing data.

Hosting, links and sharing

The current site code does not set cookies or run analytics, ads or marketing trackers. Visiting the site still sends a request to its host, GitHub Pages. GitHub says it logs visitors' IP addresses for security, whether or not they are signed in. GitHub handles those logs under its privacy statement. The clear button below cannot erase GitHub's logs.

This preview does not transmit profile, checkout or wholesale form entries to Ikanza. If you follow a link to another website, that website handles your visit under its own practices.

Your choices and the next stage

You may browse without creating a sample profile or completing forms. You can remove preview data with the button below or your browser's site-data settings. You can also remove only the sample profile from the account preview. Since no server account or enquiry is created, there is no server-held profile here to access or correct.

Before any real account, enquiry, order or payment collection opens, Ikanza needs to publish the actual operator's identity and contact route, a full notice covering the real data flow and retention, and any separate choices needed for optional uses such as marketing. No public privacy contact is available yet for this preview.

Bahasa Melayu

Apa yang berlaku kepada maklumat anda

Maklumat yang anda masukkan

Profil contoh meminta nama dan e-mel. Jika anda membuatnya, kedua-duanya hanya disimpan dalam pelayar ini. Halaman semak pesanan contoh meminta nama, e-mel, nombor telefon, poskod dan alamat. Maklumat ini hanya digunakan pada halaman semasa anda mencuba proses semakan; ia tidak dihantar kepada Ikanza atau disimpan dalam sejarah pesanan contoh. Maklumat dalam borang borong juga tidak dihantar atau disimpan oleh laman ini, dan dipadam selepas anda melihat pengesahan contoh.

Jangan masukkan alamat, nombor telefon, e-mel atau maklumat peribadi sebenar. Demo ini tidak memerlukannya.

Apa yang disimpan oleh pelayar ini

Supaya demo ini berfungsi, laman ini menyimpan troli contoh, sehingga 12 ringkasan pesanan contoh, nama dan e-mel profil pilihan, serta pilihan bahasa dalam simpanan setempat pelayar anda (local storage). Ringkasan pesanan mengandungi nombor rujukan contoh yang dijana, bilangan item, kawasan dan tarikh penghantaran contoh, jumlah contoh serta masa ia dibuat. Ringkasan terkini juga disimpan sementara untuk sesi pelayar semasa (session storage). Tiada kata laluan atau maklumat bayaran diminta.

Data dalam simpanan setempat kekal sehingga anda memadamkannya, menggunakan butang di bawah, atau pelayar anda membuang data laman. Data sesi lazimnya tamat apabila sesi pelayar berakhir. Demo ini tidak mempunyai akaun di pelayan, sambungan kurier atau langganan e-mel. Muat semula tab Ikanza lain yang masih terbuka selepas memadam data.

Hos, pautan dan perkongsian

Kod laman semasa tidak menetapkan kuki atau menggunakan analitik, iklan atau penjejak pemasaran. Namun, melawat laman ini tetap menghantar permintaan kepada hosnya, GitHub Pages. Menurut GitHub, alamat IP pelawat direkodkan untuk keselamatan, sama ada mereka log masuk ke GitHub atau tidak. GitHub mengendalikan log tersebut menurut penyataan privasinya. Butang padam di bawah tidak boleh memadam log GitHub.

Demo ini tidak menghantar maklumat profil, semakan pesanan atau borang borong kepada Ikanza. Jika anda membuka pautan ke laman lain, laman tersebut mengendalikan lawatan anda mengikut amalannya sendiri.

Pilihan anda dan langkah seterusnya

Anda boleh melayari laman tanpa membuat profil contoh atau mengisi borang. Anda boleh memadam data contoh menggunakan butang di bawah atau tetapan data laman dalam pelayar. Anda juga boleh memadam profil contoh sahaja dari halaman akaun. Oleh sebab tiada akaun atau pertanyaan dibuat di pelayan, tiada profil di pelayan yang boleh diakses atau dibetulkan.

Sebelum akaun, pertanyaan, pesanan atau bayaran sebenar dibuka, Ikanza perlu menerbitkan identiti dan saluran hubungan pengendali sebenar, notis lengkap tentang aliran dan tempoh penyimpanan data sebenar, serta pilihan berasingan untuk perkara pilihan seperti pemasaran. Belum ada saluran hubungan privasi awam untuk laman contoh ini.

这间示例店铺如何处理资料

您填写的资料

示例账户会要求姓名和电邮；创建后，这两项资料只保存在当前浏览器。示例订单表单会要求姓名、电邮、电话、邮编和地址；这些联系方式只用于显示当前页面，不会发送给 Ikanza，也不会保存在示例订单记录中。批发咨询表单同样不会由本站发送或保存；查看示例确认页后，填写内容会清空。

请勿填写真实地址、电话、电邮或其他个人资料；展示流程不需要这些资料。

浏览器保存了什么

为运行示例流程，本站会在浏览器本地储存示例购物车、最多 12 笔示例订单摘要、可选账户的姓名和电邮，以及语言选择。订单摘要包括随机生成的示例编号、商品数量、示例送货地区和日期、示例金额及创建时间。最新一笔摘要也会暂存在当前浏览器会话中。本站不会要求密码或付款资料。

本地资料会保留到您手动清除、点击下方按钮，或浏览器自行删除网站资料；会话资料通常在浏览器会话结束时消失。本站没有服务器账户、快递连接或邮件订阅。清除后，请刷新其他已打开的 Ikanza 页面。

网站托管、链接与资料分享

目前的网站代码没有设置 Cookie，也没有使用分析工具、广告或营销追踪器。访问网站仍会向托管方 GitHub Pages 发送请求。GitHub 说明会为安全目的记录访客 IP 地址，无论访客是否登录。相关记录由 GitHub 按其隐私声明处理；下方的清除按钮无法删除 GitHub 的日志。

本站不会把示例账户、订单或批发表单的填写内容发送给 Ikanza。若您打开其他网站的链接，该网站会按其自身做法处理您的访问。

您的选择与正式营业前的安排

您可以不建立示例账户、不填写表单，直接浏览网站。可用下方按钮或浏览器的网站资料设置清除示例数据，也可仅在账户页面删除示例资料。本站没有创建服务器账户或咨询记录，因此没有存放在服务器上的个人资料可供查阅或更正。

开放真实账户、咨询、订单或付款前，Ikanza 需要公布实际经营者的身份和联系方式、说明真实资料流向与保存期限的完整隐私声明，以及营销等可选用途所需的独立选择。目前尚无公开隐私联系渠道。
